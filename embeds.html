CB6 Results Map — Embed Codes

Copy and paste any block below into a WordPress Custom HTML block (or any web page). Each is a responsive, lazy-loaded iframe that resizes to fit and includes a plain-link fallback for browsers that block frames.

WordPress note: use a Custom HTML block (not the visual editor, which strips iframes). On the city WordPress, if iframes are disabled, use the "Direct link" line at the bottom of each section instead.

Auto-resize height (recommended — frame snaps to exact content)

All three results pages now broadcast their exact height to the parent, so the frame trims to fit with no extra whitespace and no clipping, and it re-fits when a reader opens the map section. Paste one block per page. Each is self-contained; for a second page in the same post, both the id and src are already set correctly below.

Auto-height embed — NY-10
<div style="width:100%;max-width:680px;margin:0 auto;border:1px solid #ece4d2;border-radius:12px;overflow:hidden">
  <iframe id="cb6frame-ny10"
    src="https://bkcb6.app/ny10-results-map.html"
    title="CB6 NY-10 Primary results by election district"
    loading="lazy" scrolling="no"
    style="width:100%;height:900px;border:0;display:block"></iframe>
</div>
<script>
(function(){
  var f=document.getElementById('cb6frame-ny10');
  window.addEventListener('message',function(e){
    if(e.origin!=='https://bkcb6.app') return;
    var h=e.data && e.data.cb6FrameHeight;
    if(h && f) f.style.height=h+'px';
  });
})();
</script>
