Every NYC Parks tree pruning work order in Brooklyn Community Board 6: Park Slope, Carroll Gardens, Cobble Hill, Red Hook, Gowanus, and the Columbia Street Waterfront District. Each dot is one tree with one work order. Each street segment is colored by the year it was last pruned, combining the ForMS work order record (2015 to today) with the older block pruning cycle record (1995 to 2016). Click a tree for the work order; click a block for its full pruning history. Open work orders are trees assigned to a pruning contract that Parks has not yet closed out.

Sources: NYC Parks Forestry Work Orders (NYC Open Data bdjm-n7q4), all pruning work order types (Block Pruning, Pruning, Prune-Traffic 10/20 Day, Canopy Reduction, Root Pruning) tagged to Community Board 306 or located inside the CB6 boundary, pulled September 8, 2026. Block pruning cycle history from NYC Parks Block Pruning (tqsy-2s6w), joined by PhysicalID to the NYC Street Centerline (inkn-q76z). Tree locations: Parks coordinates where the dataset supplies a point inside CB6 (8,100); otherwise geocoded from the work order address via NYC Planning geosearch (1,211), placed at the named park (608), or at the midpoint of the work order's street segment (31). 13 work orders with no usable address, park or segment are listed below the map and not drawn. 574 Brooklyn segment IDs in the Block Pruning dataset no longer exist in the current centerline file and could not be placed.
